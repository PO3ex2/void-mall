# Void Mall — Roadmap

> Этапы идут последовательно. Каждый заканчивается **играбельным результатом** и чек-листом «Готово, когда…».
> Проект разбит на три большие части из описания плюс общие системы:
> **A. Мир + консоль** · **B. Инвентарь, крафт и т.д.** · **C. Контроллер персонажа** · **D. Бой, лобби, сеть, полировка**

## Этап 3 — Гладкие воксели *(часть A)* ← **ждёт плейтеста**
- [x] Naive Surface Nets в том же Burst-джобе, что и блоки; стыковка с блоками (для поля блок = плотность 255, четырёхугольники — только где твёрдая сторона гладкая), бесшовность между чанками
- [x] Трипланарное текстурирование гладких материалов в шейдере блоков (слой без интерполяции — без «каши» на стыке материалов)
- [x] Материалы «Бетонный массив», «Грунт», «Ковёр (гладкий)»; тестовый мир: гладкий массив под полом и аномалии-«бездны»: скруглённая кромка ~2.5 блока и вертикальная шахта без дна (радиус 6–12 м) сквозь основание мира в пустоту; команда `anomalies`
- [x] Стык гладкой поверхности с блоками без щелей: вершины Surface Nets у блоков прижимаются к углам клеток (тест на герметичность)
- [x] Бур не замуровывает игрока, пропы и врагов
- [x] Выталкивание из вокселей по данным сетки (`EmbeddedEscape`): замурованный игрок переносится в ближайшее свободное место, а не проваливается сквозь оболочку коллизии
- [x] Смерть в пустоте (ниже −40 м): `PlayerDiedEvent` + временное возрождение на последнем безопасном месте (полноценная смерть — этап 7)
- [x] Бур (клавиша 2): `SmoothBrushCommand` через сессию, срезать/наращивать, скорость зависит от прочности, превью кисти
- [x] Добыча материалов: событие `MaterialMinedEvent`, лог в консоль (заглушка до инвентаря)
- [x] Упрощённая структурная целостность: поиск опоры «сначала вниз» с бюджетом 4096 клеток, обрушение острова физическим обломком, пыль при ударе, `DebrisImpactEvent` для будущего урона
- [x] Тесты: замкнутость поверхности, шов сферы между двумя чанками, стык с блоком, целостность (столб, консоль, якоря, бюджет)
- [ ] Плейтест: копание, наращивание, обрушения

**Готово, когда:** можно выкопать гладкую пещеру в бетонном массиве рядом с блочной стеной без швов и дыр в коллизии, а подрубленная «висящая» конструкция падает.

## Этап 7 — Выживание и состояние *(часть B)*
Решения этапа: одно здоровье + травмы-состояния (без частей тела); калории + вода + баланс жиров/белков/углеводов за сутки; рассудок с пост-эффектами (манекены-галлюцинации — позже); простая температура (воздух по месту + тепло одежды).
- [x] Модуль `VoidMall.Survival`: `VitalsModel` (чистая логика, EditMode-тесты), `PlayerVitals` (игрок), `SurvivalEnvironment` (температура, аномалии), `StatusCatalog`
- [x] Здоровье и состояния: кровотечение лёгкое/сильное, перелом ноги/руки, боль, инфекция (из открытой раны), отравление, действие обезболивающего, «Травма после смерти»; голод, жажда, усталость, холод/жара, однообразное питание, «Сыт и здоров», тревога/паника — вычисляемые
- [x] Питание: калории, вода, рацион за сутки (норма: белки 12–30%, жиры 15–40%, углеводы 35–70%); испорченная еда на полках (~25% еды) — вдвое меньше калорий и отравление
- [x] Температура: воздух по этажу/разделу/времени суток, холод у открытых холодильников, жар у бойлера, холод из бездны; одежда греет (`ItemDef.Warmth`)
- [x] Стамина — пул выживания (`IStaminaPool`): максимум режут травма, голод, инфекция; восстановление — жажда, холод, боль
- [x] Урон: падения (боль, перелом ноги), обломки и летящие пропы (`PlayerImpactEvent`), стекло и острый металл голыми руками (порез, перчатки защищают), испорченная еда, пустота
- [x] Глитч-аномалия: раз в 2 с здоровье — случайное значение от 0 до максимума (0 — смерть)
- [x] Травмы → движение (`ApplyModifiers`): переломы, шина, боль (обезболивающее глушит), голод/усталость без спринта, холод, паника — раскачка; сломанная рука бьёт медленнее
- [x] Лечение предметами: бинт (кровотечение), шина (перелом, срастается за 48 ч), обезболивающее (3 ч), антисептик (инфекция); бесполезное лекарство не тратится
- [x] HUD (полоски, плашки состояний, температура), вкладка «Состояние» (что это и как лечить, рацион), пост-эффекты (рассудок, ранение, глитч, холод)
- [x] Бодрость и сон: кровать (в мебельных), диван (хуже кровати), сон на полу из вкладки «Состояние» (до 60%, «Не выспался») и спальник (предмет → ПКМ разложить); E — спать, удержание E — взять; сон ускоряет время ×30 и сохраняет точку возрождения
- [x] Рассудок: падает в темноте (ночью быстрее), в аномалиях, сильнее при недосыпе; растёт на свету, во сне и от еды
- [x] Смерть: экран смерти с причиной, сумка с вещами по правилу `sv_death_drop` (по умолчанию — рюкзак) с меткой на экране, подбор — содержимое раскладывается; возрождение у кровати (если цела) или рядом с местом гибели; «Травма после смерти» −20% здоровья и стамины на 8 игровых часов, складывается
- [ ] Галлюцинации-манекены и звуки при низком рассудке (вместе с ИИ манекенов, этап 12)
- [ ] Глитч портит экипировку и брошенные в него предметы (см. GDD §2.5)

## Этап 8 — Крафт и навыки *(часть B)*
Решения этапа: крафт + стройка + навыки вместе; станции — верстак, швейный стол, химстол, плита и горелка; рецепты — базовые известны, сложные открываются чертежами из лута; навыки — очки аспектов за действия; износ инструментов и починка на верстаке.
- [x] Сборки `VoidMall.Crafting` (рецепты, очереди, станции) и `VoidMall.Skills` (аспекты, навыки — нижний слой, его спрашивают инвентарь, выживание, крафт, инструменты)
- [x] `RecipeDef` (результат, ингредиенты, станция, время, категория, чертёж, требуемый навык) — 32 рецепта; `CraftQueue` до 8 позиций: ингредиенты списываются при постановке, отмена возвращает
- [x] Очереди: руки — всегда; верстак, швейный стол, химстол — пока открыто окно станции; плита и горелка — сами, пока есть топливо (доски, картон, газовый баллончик); готовое у станции — в выдаче; «Станция занята» для второго игрока
- [x] Станции — физические пропы: E — окно, удержание E — взять/тащить; в мире (строймаркет, подсобки — верстак, одежда — швейный, фудкорт — плита, аптека — химстол), крафт из досок и металла
- [x] Вкладка «Крафт» и окно станции: список (поиск, станция, «можно сейчас»), карточка, производство (ингредиенты, количество, очередь с прогрессом и отменой)
- [x] Чертежи (ПКМ — изучить), рецепты с требованием навыка (перфоратор — «Техник» 2)
- [x] Износ инструментов (удары, бур, горение факела) и починка на верстаке; электроинструмент — только с «Техником»
- [x] Плита: блюда (сбалансированы, +рассудок), прогрев испорченной еды
- [x] Стройка: призрак-предпросмотр для пропов из инвентаря (зелёный/красный, R — повернуть, ПКМ — поставить): станции, стол, стеллаж, баррикада, спальник; блоки из материалов на верстаке

## Этап 8А — Функциональные блоки и формы *(часть A/B)* ← **ждёт плейтеста**
- [x] Четвёртый тип геометрии: функциональный блок — материал вида `Functional` с размером в клетках и функцией (`MaterialDef.Function`, `FunctionalSize`); без физики, ставится и ломается целиком

- [x] **Двери**: в части проходов между комнатами и в дверях лестничных клеток (двойные — петли по краям), E — открыть/закрыть, открываются от игрока, не закрываются на стоящем в проёме; крафт на верстаке, ставятся призраком (R — поворот); проём над дверью заложен стеной
- [x] **Большие ворота** на месте рольставен: половина заперта (поддеть ломом — удержание E), остальные — E; открывается весь проём
- [x] **Автоматические стеклянные двери** во входах магазинов (вместо части открытых проёмов) — цельный блок 1×3, 2×3 или 4×3 (вход 4 — всегда одна дверь 4×3: у двух 2×3 рядом внутренние створки съезжались в середину и перекрывали проход): створки разъезжаются все вместе, когда игрок подходит (одна проверка на блок, 10 раз в секунду), и закрываются за ним; у 4×3 внутренние створки уезжают телескопом; состояние у каждого клиента своё (по близости игроков), в сетке не хранится; крафт на верстаке (Техник 1, широкая — Техник 2)
- [x] **Шаблоны формы**: полублок, ступенька, скос, внутренний и внешний угол, круглый скос наружу и внутрь, столб, стенка в полблока, тонкая панель (ею же генератор ставит витрины и прямые участки стеклянных ограждений); 24 ориентации: R — поворот вокруг вертикали, Shift+R — наклон (верх смотрит вверх, вниз или в одну из 4 сторон), Shift+колесо — форма; у потолка сам переворачивается. Набор шаблонов не тратится: призрак без коллизии → ПКМ блоком заполнить, сломал — вернулся блок
- [x] Станция **дробилка / компрессор** (техэтаж, крафт на верстаке): блоки → бетонная крошка, крошка → бетонные блоки

## Этап 8Б — Мир 2: биомы и особые разделы *(часть A)* ← **ждёт плейтеста**

- [x] **Заброшенный вид**: поваленные стеллажи (товар рассыпан рядом), кучи мусора — понемногу в обычном моле, больше в пустом биоме
- [x] **Ящики с лутом** на техэтаже: разбить — выпадает 2–4 вещи и облако пенопласта; целые — тяжёлые пропы для укрытия и баррикад
- [x] **Балкончики**: ~35% полос галерей без атриума — проём 6 клеток посередине через этажи выше первого, стеклянное ограждение, проходы-балконы у витрин, мостик поперёк; фонтан всегда на первом торговом этаже, над ним круглый проём с ограждением до светового фонаря; у ламп на краю проёма бока — плитка потолка
- [x] **Кассы**: в крупных магазинах — ряд стоек поперёк выхода у витрины с дверью, за ними стойки с мелочью (свой лут), в мелких — одна касса у входа; кассовый аппарат вскрывается ломом (удержание E, один раз — 1–2 вещи)
- [x] **Технический этаж без ламп**: ни потолочных, ни аварийных, автодверей тоже нет (открытые проёмы) — светят только **строительные лампы** на треногах с автомобильными аккумуляторами (часть разряжена; зарядка — потом, с электричеством); аккумулятор — предмет (лут, разбор лампы)
- [x] Колонна круглой площади без фонтана — из закруглённых блоков (круглое сечение)
- [x] Исправлено: ступенька в проёме лифта (деревянные двери с перемычкой в части проёма — у лифта теперь только свои двери), замок рольставни виден с обеих сторон, товары выпрыгивали из стойки у кассы (коллизия по полкам), рамка прицела и трещины у функциональных блоков — на весь блок
