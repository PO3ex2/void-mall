# Void Mall — Roadmap

> Этапы идут последовательно. Каждый заканчивается **играбельным результатом** и чек-листом «Готово, когда…».
> Проект разбит на три большие части из описания плюс общие системы:
> **A. Мир + консоль** · **B. Инвентарь, крафт и т.д.** · **C. Контроллер персонажа** · **D. Бой, лобби, сеть, полировка**

## Этап 3 — Гладкие воксели *(часть A)* ← **ждёт плейтеста**
- [x] Naive Surface Nets в том же Burst-джобе, что и блоки; стыковка с блоками (для поля блок = плотность 255, четырёхугольники — только где твёрдая сторона гладкая), бесшовность между чанками
- [x] Трипланарное текстурирование гладких материалов в шейдере блоков (слой без интерполяции — без «каши» на стыке материалов)
- [x] Материалы «Бетонный массив», «Грунт», «Ковёр (гладкий)»; тестовый мир: гладкий массив под полом и аномалии-«бездны»: скруглённая кромка ~2.5 блока и вертикальная шахта без дна (радиус 6–12 м) сквозь основание мира в пустоту; команда `anomalies`
- [x] Стык гладкой поверхности с блоками без щелей: вершины Surface Nets у блоков прижимаются к углам клеток (тест на герметичность)
- [x] Бур не замуровывает игрока, пропы и врагов
- [x] Выталкивание из вокселей по данным сетки (`EmbeddedEscape`): замурованный игрок переносится в ближайшее свободное место, а не проваливается сквозь оболочку коллизии
- [x] Смерть в пустоте (ниже −40 м): `PlayerDiedEvent` + временное возрождение на последнем безопасном месте (полноценная смерть — этап 7)
- [x] Бур (клавиша 2): `SmoothBrushCommand` через сессию, срезать/наращивать, скорость зависит от прочности, превью кисти
- [x] Добыча материалов: событие `MaterialMinedEvent`, лог в консоль (заглушка до инвентаря)
- [x] Упрощённая структурная целостность: поиск опоры «сначала вниз» с бюджетом 4096 клеток, обрушение острова физическим обломком, пыль при ударе, `DebrisImpactEvent` для будущего урона
- [x] Тесты: замкнутость поверхности, шов сферы между двумя чанками, стык с блоком, целостность (столб, консоль, якоря, бюджет)
- [ ] Плейтест: копание, наращивание, обрушения

**Готово, когда:** можно выкопать гладкую пещеру в бетонном массиве рядом с блочной стеной без швов и дыр в коллизии, а подрубленная «висящая» конструкция падает.

## Риски
| Риск | Что делаем |
|---|---|
| Стыковка блоков и Surface Nets даёт швы или дыры | Отдельный этап 3, полигон для стыков, плотность блоков = 255 |
| Бесшовный портал в URP (рекурсия, клиппинг, мерцание при телепорте) | Прототип портала можно сделать раньше этапа 10 как спайк |
| World-space UI Toolkit не поддерживает нужный ввод | Fallback: RenderTexture + `SetScreenToPanelSpaceFunction` |
| Навигация ИИ по разрушаемому миру | Решение на этапе 12 после прототипа, A* по сетке как запасной вариант |
| Сейвы «всё посещённое» растут | Палитра + RLE + сжатие, однородные чанки хранятся одним значением |
| Добавлять кооп поздно | Правило «мутации только через команды» с этапа 0, ревью на каждом этапе |
| 16 игроков в разных концах мира перегружают хост | Interest management, общий пул колонн, бюджеты генерации, генерация нетронутых колонн на клиенте, позже — выделенный сервер |
| 5 этажей × бесконечный XZ — много геометрии и ламп | Однородные чанки хранятся одним значением, occlusion culling (между этажами — перекрытия), лимит realtime-ламп |
