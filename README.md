# Void Mall

Песочница-выживание от первого лица в бесконечном лиминальном торговом центре.
Блоки и воксели, разрушаемый мир, физика в духе Source, крафт, кооператив (позже).

- Движок: Unity 6000.6.4f1, URP
- Документы: [Game Design](Assets/GAME_DESIGN.md) · [Architecture](Assets/ARCHITECTURE.md) · [Roadmap](Assets/ROADMAP.md) · [Исходное описание](Assets/GAME_DESCRIPTION.md)

## Клонирование
Нужен [Git LFS](https://git-lfs.com):
```
git lfs install
git clone https://github.com/PO3ex2/void-mall.git
```

## Запуск полигона контроллера
1. Открыть сцену `Assets/_Project/Scenes/Sandbox_Controller.unity` и нажать Play.
2. Если ассеты потерялись или нужно пересобрать полигон — меню **Void Mall → Setup → All**.

| Действие | Клавиатура и мышь | Геймпад |
|---|---|---|
| Движение / взгляд | WASD / мышь | левый / правый стик |
| Прыжок | Space | A |
| Присесть | Ctrl или C | B |
| Спринт / медленный шаг | Shift / Alt | L3 / — |
| Консоль | `` ` `` (Ё) | — |
| HUD движения / панель веса и травм | F3 / F4 | — |

Полезные команды консоли: `help`, `noclip`, `fly`, `tp x y z`, `getpos`, `time_scale 0.2`, `fov 90`, `sensitivity 0.1`.

## Полигон мира: мол
Сцена `Assets/_Project/Scenes/Sandbox_World.unity` (собирается меню **Void Mall → Setup → Build World Sandbox**): бесконечный мол — парковки P2/P1, 5 торговых этажей, технический этаж. Игрок появляется в галерее первого этажа.

| Действие | Клавиши |
|---|---|
| Слот хотбара | 1–9 / колесо |
| Действие предмета в руке: ударить, есть, надеть, включить фонарик | ЛКМ |
| Поставить блок (блок в руке) / нарастить массив (перфоратор, тратит грунт или крошку) | ПКМ |
| Перфоратор: срезать гладкий массив | ЛКМ (удержание) |
| Инвентарь и экипировка (перетаскивание, R — повернуть, ПКМ — использовать, Shift+клик — переложить, за окно — выбросить) | Tab |
| Взять предмет с полки или с пола | E (прицелом) |
| HUD (позиция, этаж, раздел, время, освещённость) | F3 |
| Карта этажа | F6 |
| Проп: взять (до 20 кг) или тащить (до 300 кг) / отпустить | E |
| Кровать, диван или спальник: лечь спать (точка возрождения) / кровать — взять, спальник — свернуть в инвентарь | E / удержание E |
| Постройка в руке (станция, мебель, баррикада, спальник): поставить / повернуть | ПКМ / R |
| Крафтовая станция: открыть окно / взять | E / удержание E |
| Крафт в руках, навыки | Tab → «Крафт», «Навыки» |
| Проснуться / возродиться после смерти | E |
| С пропом в руках: бросить / повернуть на 45° (Shift — наклонить) / ближе-дальше | ЛКМ / R / колесо |
| Прибить ношу к стене, полу или другому пропу (с молотком) | ПКМ |
| Вытащить гвозди / аккуратно разобрать проп | удержание E / удержание F |
| Сломать проп | молоток, ЛКМ |

Команды пропов: `props_list`, `prop_spawn chair` (создать перед собой), `props_info`, `world_props 0`, `world_prop_radius 80`, `sv_hold_mass 20`, `sv_drag_mass 300`.

Команды мола: `where` (где я), `anomalies` (ближайшие аномалии), `goto_anomaly abyss|pool|cutout|distortion|glitch`, `time 22.5` (время суток, ночью свет гаснет), `time_daylength 60`, `time_frozen 1`, `seed 42` (пересоздать мир), `regen_chunk`, `world_props 0`, `world_prop_radius 80`, `r_lamplights 40`, `r_lampshadows 2`, `fx_anomaly_strength 1`.

Команды мира: `blocks`, `setblock x y z материал`, `fill x1 y1 z1 x2 y2 z2 материал`, `world_info`, `r_viewdistance 8`, `tool_hand_damage 15`, `drill_radius 2`, `debug_mining_log 0`.

Команды предметов: `give hammer` / `give nails 50` / `give block.concrete 32` (Tab дополняет ID), `items_list [фильтр]`, `inventory`, `clear_inventory`, `loot_info`, `sv_creative 1` (блоки и гвозди не тратятся), `sv_carry_capacity 30`, `sv_loot_scale 1` (заполненность полок), `r_itemdistance 35`. Игрок начинает с пустыми руками: всё нужное находится на полках или добывается. Иконки после замены моделей: **Void Mall → Setup → Render Item Icons**.

Выживание: справа внизу — здоровье, стамина, сытость, вода, бодрость, рассудок и плашки состояний, подробно — вкладка «Состояние» (Tab). Там же — «Поспать на полу» (до 60% бодрости, потом «Не выспался»). Команды: `vitals`, `hurt 30`, `heal`, `status_add bleeding|bleeding_heavy|fracture_leg|fracture_arm|pain|infection|poisoning|trauma`, `status_clear`, `set_need food|water|rest|sanity|temp значение`, `kill`, `respawn`, `god 1`, `sv_death_drop 0..3` (что теряется при смерти: ничего, хотбар, рюкзак, всё), `sv_sleep_speed 30`.

Крафт и навыки: вкладки «Крафт» и «Навыки» в окне Tab, станции открываются E. Команды: `recipes [фильтр]`, `craft_learn <рецепт>`, `craft_unlock_all 1` (все рецепты без чертежей и навыков), `craft_instant 1`, `skills`, `skill_points <аспект> <очки>`, `skill_set <навык> <уровень>`, `skills_reset`, `sv_skill_rate 1`.

Замеры лагов: `perf_run 600 9 20` (через 20 с забег 600 м по направлению взгляда со скоростью 9 м/с и отчёт), `perf_record 20` (20 с записи, пока бегаешь сам). Отчёт — в консоли и в `Temp/VoidMallPerf.txt`: худшие кадры и какие системы их заняли.

Консоль: Tab дополняет команды и аргументы (материалы, виды аномалий, 0/1). Настройки (чувствительность, FOV, графика) сохраняются в `config.cfg` в папке данных игры, свои команды при старте — в `autoexec.cfg`; `exec файл`, `host_writeconfig`.

Подрубленная конструкция, которая больше ни на что не опирается, падает обломком. Бездна прорезает этажи до пустоты под миром: упал ниже −40 м — погиб.
